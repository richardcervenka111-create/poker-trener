# Poker tréner

Tréning rozhodovania v No-Limit Hold'em bez peňazí a bez účtu: preflop podľa pozície, pot odds, bankroll a riziko krachu, pravidlá zisku. Jeden súbor, žiadne sledovanie.

Live: **https://richardcervenka111-create.github.io/poker-trener/**

## Prečo

Väčšina hráčov prehráva nie preto, že nevie blafovať, ale preto, že hrá priveľa rúk z nesprávnej pozície a platí za dorovnanie viac, než je jeho šanca. Tieto tri veci sa dajú natrénovať za pár večerov, bez jediného franku.

## Čo obsahuje

- **Preflop**: náhodná ruka a pozícia, odpoveď fold / raise / limp, okamžité vysvetlenie s poradím ruky zo 169 kombinácií
- **Pot odds**: pot, stávka, počet outov, rozhodnutie call / fold s výpočtom
- **Bankroll**: riziko krachu pre daný bankroll, buy-in, zisk a rozptyl, a koľko treba na 5 %
- **Pravidlá zisku**: osem viet, ktoré dlhodobo rozhodujú

## Poctivo

Rozsahy sú zjednodušené (percentá najlepších rúk podľa pozície), nie GTO. Smer je správny, detaily nie sú svätým písmom. Poker je hra s rozptylom a väčšina hráčov dlhodobo prehráva. Vo Švajčiarsku sú legálne len prevádzkovatelia s licenciou ESBK.
